ZAI Notebooks

Your own slice of an H200.

A private JupyterLab server with a hardware-isolated share of the GPU, ready in about fifteen seconds.

  • GPUNVIDIA H200 · MIG 1g.18gb, 7 slices
  • VRAM18 GB, yours alone while your server runs
  • Home10 GB private storage, kept between sessions
  • IdleServer stops after 60 min; your files stay
How it works
How it works
  1. Request access with a username and password.
  2. An administrator approves your request. Nothing to do until then.
  3. Sign in and pick a size: GPU for CUDA work, CPU-only for everything else.
  4. Work in JupyterLab. Start with Welcome.ipynb; it checks your GPU live.
Built-in AI: caimex
Built-in AI: caimex

Every server ships with caimex, an AI coding assistant that works across your whole project — not just one cell. It is preinstalled and already signed in.

In JupyterLab open File → New → Terminal, then:

$ cd my-project
$ caimex               # chat about this folder
$ caimex run "fix train.py"
