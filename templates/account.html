Use it from your own machine

  1. Make an API token on the API tokens page. Treat it like a password: it can start servers that spend your credit.
  2. Get the command-line tool (Python 3, nothing else to install):
    curl -fsSLo zai https://{{ public_host }}{{ base_url }}zai/cli && chmod +x zai ./zai login https://{{ public_host }} ./zai sizes ./zai start --size {{ catalog.default_size.slug }} --wait
  3. SSH, scp, VS Code Remote-SSH. Add your public key to ~/.ssh/authorized_keys on your server, then:
    ./zai ssh-config >> ~/.ssh/config ssh zai
  4. Reach a port. Anything listening inside your server, on port 8000 say, is at
    https://{{ public_host }}/user/{{ user.name }}/proxy/8000/
    Your browser login works there. From code, send Authorization: Bearer <token>; OpenAI-compatible clients accept the token as their API key. Nobody without a token for your account can reach it.
